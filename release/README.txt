# 香料管理系统 使用说明

## 🚀 快速开始
1. 双击 "香料管理系统.exe" 启动程序
2. 首次运行会自动创建数据库
3. 开始管理你的香料库存和配方

## 🧪 AI调香专家（香韵大师）—— 本次新增
内置「资深调香师专家」：GC-MS全谱解析、香韵结构重组（五层骨架+香韵分路）、
双版本配方输出（极致还原版 + 合规落地版）、雾化工程化适配（GB 2760 / GB 41700 / TPD / PMTA）。

### 首次使用（需联网）
1. 点击侧边栏「AI调香专家」→ 右上角「⚙️ 模型设置」
2. 选择服务商预设（智谱GLM / DeepSeek / Kimi / OpenAI / 自定义OpenAI兼容接口）
3. 填入自己的 API Key 与模型名称，点「测试连接」确认
   （API Key 仅保存在本机 ai_expert_config.json，不会上传）

### 核心用法
- **快捷场景**：逆向仿香 / 新香型开发 / 配方合规改造 / 雾化问题诊断 / 单体咨询
- **附上系统数据**：右侧可勾选把软件内的原料库、配方库、GC-MS分析发给专家，
  专家会基于你的真实数据工作；也可指定单个配方或单个GC-MS分析
- **完整配方报告**：勾选「按九大章节输出完整配方报告」后提问，
  输出含双版本配方、香韵分路分析、合规审查、雾化适配的完整报告
- **导出报告**：对话可导出为 report.md + report.html（存于 deliveries/ 目录）
- **记忆学习**：专家每次回答会提炼「候选知识」，在「📚 记忆库 → 候选库」中
  确认升格后成为生效知识，后续对话自动应用（候选/生效闸门，防止污染）

## 📊 数据同步功能（可选）
- 默认情况下数据同步功能是关闭的
- 如需启用，请联系软件提供方获取服务器地址
- 启用后可以实现多设备数据同步

## 🔧 功能特性
- ✅ 原料管理：添加、编辑、删除香料原料
- ✅ 配方管理：创建和管理调香配方
- ✅ 库存管理：跟踪原料库存和使用记录
- ✅ GC-MS分析：管理气相色谱-质谱分析数据
- ✅ AI调香专家：内置香韵大师专家，AI辅助配方设计与分析
- ✅ 智能分析：配方相似度、成本预测、库存优化、数据可视化
- ✅ 数据统计：生成各种统计图表
- ✅ 数据导入导出：支持Excel文件导入导出
